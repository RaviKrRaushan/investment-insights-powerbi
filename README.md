# 📊 Investment Insights and Savings Analysis

This repository contains the project I completed as part of my **Power BI internship at Config Technology**. The objective of the project was to analyze investment behavior and savings patterns using interactive dashboards and insightful visualizations.

---

## 🚀 Project Overview

The project focuses on extracting meaningful insights from investment-related data, analyzing investor behavior, and visualizing patterns using **Power BI**. It includes the creation of slicers, dynamic dashboards, and reports that answer key business questions.

---

## 🎯 Objectives

- Understand investment patterns across different age groups and genders
- Analyze reasons for investment (retirement, education, emergencies, etc.)
- Identify how frequently people invest and for how long
- Determine trusted sources of financial information
- Deliver a clean, interactive Power BI dashboard with actionable insights

---

## 📌 Key Features

- Interactive slicers and filters for deep-dive analysis
- Age and gender-wise investment patterns
- Investment monitoring frequency visualization
- Distribution of investment durations
- Insights into trusted investment information sources
- Professionally formatted and published Power BI dashboards
